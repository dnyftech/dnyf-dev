# DNYF-DEV

DNYFTECH development infrastructure and runtime engineering workspace.

## Architecture

DNYF-DEV contains the DNYFTECH runtime, development tooling, registry infrastructure, capability negotiation, service discovery, security protocols, and engineering modules.

## Completed Security / Runtime Phases

- Phase 8G — Authenticated Session Security
- Phase 8H — Unified Device Registry
- Phase 8I — Capability Negotiation
- Phase 8J — Service Discovery Registry

## Security Model

The DNYF runtime enforces:

- Ed25519 cryptographic identity
- SHA-256 fingerprints
- Proof of possession
- Authenticated sessions
- Replay protection
- Persistent revocation
- Local approval gates
- Capability/trust separation
- Capability/authorization separation
- Self-trust disabled
- Self-pairing disabled
- Automatic trust disabled
- Remote execution disabled
- Remote installation disabled
- Remote shell disabled
